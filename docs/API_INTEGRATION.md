# Интеграция с SStats API

## Базовый URL
`https://api.sstats.net`

## Авторизация
- Без ключа: 30 запросов/мин на IP, 300 общих.
- С ключом: расширенные лимиты (ключ передаётся как `apikey` в параметрах).

## Используемые эндпоинты

| Эндпоинт | Назначение | Метод |
|----------|------------|-------|
| `/leagues` | Получение списка лиг | `get_leagues()` |
| `/games/list?today=true` | Получение live-матчей | `get_live_matches()` |
| `/games/{id}` | Детальная статистика матча | `get_match_details(id)` |
| `/odds/{gameId}` | Доматчевые коэффициенты | `get_match_odds(id, live=False)` |
| `/odds/live/{gameId}` | Live-коэффициенты | `get_match_odds(id, live=True)` |
| `/games/glicko/{gameId}` | Прогнозы Glicko 2 | `get_glicko(id)` |
| `/games/list?team1=X&team2=Y&ended=true` | Личные встречи | `get_head_to_head(team1, team2)` |
| `/games/list?team=X&ended=true` | Последние матчи команды | `get_team_recent_matches(team_id)` |

## Обработка данных
- Методы возвращают агрегированные статистики (средние, суммы).
- Для предматчевого анализа методы расширены для возврата списков результатов.

## Ограничения и кэширование
- Текущий клиент использует задержку 2 секунды между запросами.
- В будущем планируется кэширование ответов.
