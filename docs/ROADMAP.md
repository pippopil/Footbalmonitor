## 💰 Релиз 3.0 (Пользователи и монетизация)

### Эпик 3.1: Система регистрации и авторизации
- [ ] Создать таблицу `users` с полями: id, email, password_hash, tariff, tariff_expiry, telegram_chat_id
- [ ] Реализовать регистрацию и вход (JWT или сессии)
- [ ] Защитить API и веб-страницы авторизацией

### Эпик 3.2: Тарифы и платежи
- [ ] Определить тарифы: месяц, 3 месяца, 6 месяцев, год, навсегда
- [ ] Интеграция с платёжным шлюзом (например, Stripe, или через Telegram Payments)
- [ ] Проверка прав доступа к функциям на основе тарифа

### Эпик 3.3: Управление ботами через интерфейс
- [ ] Позволить пользователю добавлять и удалять Telegram-ботов (токены) через интерфейс
- [ ] Хранить токены в БД, привязанные к пользователю
- [ ] При запуске планировщика использовать токены всех активных ботов
