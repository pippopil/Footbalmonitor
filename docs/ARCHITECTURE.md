# Архитектура Football Monitor

## Общая структура

- **Backend**: Python 3.11, FastAPI, APScheduler, SQLite (в дальнейшем PostgreSQL)
- **Веб-интерфейс**: Jinja2 шаблоны, Bootstrap (серверный рендеринг)
- **Бот**: python-telegram-bot (асинхронный)
- **API клиент**: requests с ограничением частоты запросов

## Модули

| Модуль | Назначение |
|--------|------------|
| `app/main.py` | Точка входа, запускает веб-сервер, бота и планировщик в потоках |
| `app/config.py` | Конфигурация (переменные окружения, пути) |
| `app/database.py` | Работа с SQLite (пользователи, фильтры, чёрный список, сигналы) |
| `app/sstats_client.py` | Клиент для SStats API (GET-запросы, агрегация статистики) |
| `app/filter_engine.py` | Движок проверки фильтров против данных матча |
| `app/scheduler.py` | Планировщик, опрашивает API, применяет фильтры, отправляет уведомления |
| `app/telegram_bot.py` | Telegram-бот для регистрации пользователей и отправки сообщений |
| `app/excel_exporter.py` | Экспорт сигналов в Excel |
| `app/web/routes.py` | Маршруты FastAPI, обработка форм, рендеринг шаблонов |
| `app/web/templates/` | HTML-шаблоны для веб-интерфейса |
