# Функциональные возможности Football Monitor

## Основные возможности

- Мониторинг live-матчей в реальном времени
- Гибкая фильтрация по:
  - Времени матча
  - Общей и индивидуальной статистике (голы, угловые, удары, удары в створ, ЖК)
  - Коэффициентам (П1, П2, Ничья, Тотал 2.5)
  - Разнице статистики между командами
  - Предматчевому анализу на основе H2H и последних матчей
- Чёрный список лиг
- Отправка уведомлений в Telegram (через BotGate или напрямую)
- Экспорт срабатываний в Excel
- Веб-интерфейс для управления фильтрами и просмотра сигналов

## Планируемые расширения

- Разделение фильтров по вкладкам
- Вкладка «Сигналы» с историей и обновлением в реальном времени
- Отслеживание сигналов на протяжении матча с финальным результатом
- Система регистрации и тарифов (монетизация)
- Поддержка нескольких Telegram-ботов на одного пользователя
- Десктоп-приложение (.exe) с кнопкой запуска/остановки
- Мобильное приложение для Android
- Интеграция с Glicko 2 (прогнозы xG и вероятностей)
- Улучшенные алгоритмы анализа (машинное обучение)
