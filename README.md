**Footbalmonitor Pro** — это профессиональный аналитический терминал спортивной телеметрии, позволяющий трейдерам, капперам и спортивным аналитикам:
1. Мониторить матчи в режиме реального времени с задержкой менее 2-3 секунд.

3. Получать моментальные алерты со сводкой xG, опасных атак и котировок в персональные Telegram-каналы.
4. Отслеживать реальную математическую эффективность стратегий без риска реальных денег через виртуальный трекер банкролла.
5. Использовать AI-аналитика на базе нейросетей для мгновенной оценки вероятности гола.

## 🔍 Лайв-мониторинг и карточка матча (Match Inspector)

### Поиск по ID матча и кодам команд
Строка поиска над списком матчей поддерживает:
- **Поиск по ID**: ввод `m-1`, `#m-1`, `id:m-1` или цифры `1` моментально находит конкретное событие.
- **Поиск по тикерам команд**:
  - `ARS` ➔ Arsenal
  - `CHE` ➔ Chelsea
  - `LIV` ➔ Liverpool
  - `BAY` ➔ Bayern Munich
  - `NAP` ➔ Napoli
  - `RMA` ➔ Real Madrid
  - `BAR` ➔ Barcelona
  - Поддержка составных кодов: `ARS-CHE`, `ARS vs CHE`, `LIV-AVL`.
- **Быстрые чипы**: ряд кликабельных тегов (`#m-1`, `ARS`, `CHE`, `LIV`, `BAY`, `NAP`, `RMA`) для фильтрации в один клик.
- **Интерактивные бейджи на карточках**: каждый матч в списке отображает кликабельный `#ID` и тикеры команд `[ARS]`, клик по которым автоматически применяет фильтр.

### Генератор брендированных карточек счёта (Canvas API)
В заголовке карточки инспектора (`#match-inspector-card`) рядом с названиями команд расположена кнопка **«Поделиться счётом»**:
- Автоматически рендерит карточку 1200×675 с тёмным градиентом и декоративной разметкой футбольного поля.
- Отображает крупный счёт, минуту матча, статус (LIVE/HT/FT), флаг страны, лигу и тикеры команд.
- Включает блок ключевой телеметрии:
  - Суммарный xG обеих команд.
  - Опасные атаки (DA) и разницу атак.
  - Удары в створ и общее количество угловых.
  - Индекс давления (Pressure Index) с маркером вероятности гола.
- Позволяет в один клик:
  - Скачать готовый PNG.
  - Скопировать картинку в буфер обмена.
  - Отправить через Native Web Share (Telegram, WhatsApp, соцсети).

### График атакующего тренда и стабильности моментума (Sparkline)
Компонент `OffensiveTrendSparkline` расположен внутри `#match-inspector-column` прямо под блоком «Статистика матча в реальном времени»:
- Строит сглаженные sparkline-кривые динамики атак хозяев (изумрудный) и гостей (циан) по отрезкам матча.
- Рассчитывает **Коэффициент стабильности моментума (%)** на основе математической дисперсии давления.
- Отображает бейдж текущего штурма (например, `Штурм: Arsenal (+18 DA за последние 15 минут)`).
- Сравнивает темп атак в минуту (APM) между соперниками.

## 🛰 Источники данных, Watchdog 30s и авто-ротация Failover

Платформа поддерживает 8 провайдеров телеметрии:
1. `⚡ Flashscore`: парсер мобильных зеркал с защитой от Cloudflare.
2. `⚽ Sofascore`: браузерный релей без блокировок.
3. `🔴 Фонбет Live`: легальная линия РФ, реальный эфир.
4. `🔷 1xBet Live`: сверхширокая роспись молодежных и региональных лиг.
5. `📊 SStats.net`: официальный REST API.
6. `⚡ API-Football (v3)`: мировой охват турниров.
7. `🌐 Public Feed`: открытый поток данных.
8. `🎮 Демо-генератор`: автономная песочница для тестирования без сети.

### Защита от сбоев (30s Failover Watchdog)
- В фоновом режиме работает сторожевой таймер. Если действующий источник не присылает обновления более 30 секунд, система автоматически переключается на следующий узел из кольцевого пула failover.
- Для обычных пользователей идентификатор поставщика скрыт и отображается как нейтральное ядро: `🛰️ Live Telemetry Core (Автоматическая балансировка)`.

## 🎯 Движок фильтров и полный каталог 55 стратегий

Движок `evaluateFilterRule` проверяет более 40 параметров в каждом матче:
- Минуты матча (`minMinute` – `maxMinute`).
- Точный счёт или условия (`ANY`, `DRAW`, `0-0`, `HOME_LEAD`, `AWAY_LEAD`, `ONE_GOAL_DIFF`, `TOTAL_UNDER_2`, `BTTS_NO`).
- Опасные атаки (DA), общее число атак, разница атак.
- Удары в створ (SOT), удары мимо, заблокированные удары.
- Угловые (всего, разница, угловые уступающего фаворита).
- Жёлтые и красные карточки, фолы.
- xG (ожидаемые голы), дефицит xG при ничьей или отставании.
- Коэффициенты букмекеров (1X2, ТБ 0.5, ТБ 1.5, ТБ 2.5, Обе забьют).

## 🏒 Многовидовое разграничение спорта (Multi-Sport Demarcation)

Платформа поддерживает 6 видов спорта с абсолютной изоляцией:
- ⚽ **Футбол** (`football`): таймы 45', xG, угловые, ЖК/КК.
- 🏒 **Хоккей** (`hockey`): 3 периода по 20', броски в створ, штрафное время.
- 🏀 **Баскетбол** (`basketball`): 4 четверти, фолы, трехочковые попадания.
- 🏐 **Волейбол** (`volleyball`): партии до 25 очков, эйсы, блоки.
- 🎾 **Большой теннис** (`tennis`): сеты, геймы, брейк-поинты.
- 🏓 **Настольный теннис** (`table_tennis`): партии до 11 очков.

Футбольные стратегии никогда не срабатывают на хоккее или баскетболе благодаря валидатору `inferSportFromRule`.

## 💰 Виртуальный трекер банка и 100% Legal-архитектура

Платформа категорически **не принимает ставки** и не управляет счетами БК:
- **`BankrollTrackerModal.tsx`**: виртуальный тренажёр (Paper Trading).
- Ведение виртуального банка в рублях, долларах или USDT.
- Расчёт ROI (%), Win Rate (%), максимальной просадки (Drawdown) и винстриков.
- Стратегии менеджмента: фиксированный флэт или критерий Келли.

## 🚀 Запуск, сборка, тестирование и окружение

### Запуск проекта
```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Проверка типов TypeScript
npm run lint

# Запуск модульных тестов Vitest (35 тестов)
npm run test:vitest

# Запуск алгоритмического комплекса (92 теста)
npm test

# Сборка production бандла
npm run build
```
