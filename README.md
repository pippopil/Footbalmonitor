# Football Monitor

Приложение для мониторинга футбольных матчей в реальном времени с расширенными фильтрами и отправкой уведомлений в Telegram.

## Установка
1. Клонировать репозиторий
2. Установить зависимости: `pip install -r requirements.txt`
3. Настроить `config.py` (API-ключ SStats, токен Telegram-бота)
4. Запустить: `python -m app.main`

## Возможности
- Фильтрация по времени матча, голам, угловым, ударам, карточкам (общая и индивидуальная статистика)
- Фильтрация по коэффициентам (П1, П2, Ничья, Тотал 2.5)
- Учёт личных встреч и последних матчей команд
- Чёрный список лиг
- Уведомления в Telegram (через BotGate)
- Экспорт срабатываний в Excel
- Веб-интерфейс для управления фильтрами
